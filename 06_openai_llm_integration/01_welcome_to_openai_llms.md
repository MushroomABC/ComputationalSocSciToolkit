# 🤖 06_OpenAI与大语言模型在社会科学中的应用 (OpenAI & LLMs for Social Science)

## 为什么社科研究者需要 OpenAI & LLMs？
在传统社会科学研究中，处理非结构化数据（如数千份政治演说、访谈逐字稿、新闻报道或开放式问卷回答）往往需要大量人工编码（Qualitative Coding）。

结合 **OpenAI API (GPT-4o/Codex)** 与 **Python / Terminal**，社科研究者能够：
1. **自动定性编码 (Automated Qualitative Coding)**：利用 Prompt Engineering 对大批量社科文本进行主题分类与情感分析。
2. **合成数据生成 (Synthetic Data Generation)**：生成符合特定人口统计分布的合成问卷数据，用于教学与隐私敏感研究。
3. **代码与数据流自动化 (AI-Assisted CSS Workflow)**：通过 Terminal CLI 与 OpenAI Codex 加速量化分析代码的生成与调试。

## 本目录文件导航
- `01_openai_api_quickstart.py`: 如何在 Python 中设置环境变量并安全调用 OpenAI API。
- `02_prompt_engineering_for_socsci.py`: 社科文本分类与结构化提取的 Prompt 提示词工程示例。
- `03_llm_synthetic_data_generator.py`: 利用 OpenAI 生成用于研究测试的合成民调数据。
- `04_terminal_codex_workflow.md`: 在 Terminal (命令行) 中配合 OpenAI Codex 提升研发效率指引。
