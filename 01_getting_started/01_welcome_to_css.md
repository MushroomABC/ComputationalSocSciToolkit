# 🚀 欢迎来到计算社会科学与 AI 赋能研究 (CSS & AI Research)

## 什么是计算社会科学与 AI 赋能？
计算社会科学（CSS）是将计算机技术（如数据预处理、网络分析、统计建模）与 **人工智能/大语言模型 (OpenAI API, Codex, GPT-4o)** 应用到政治学、社会学、经济学、公共管理等领域的交叉学科。

## 社科生与 AI 结合的 3 大研究范式
1. **传统编程 + AI 助推**：利用 Python 完成数据清洗与统计分析，用 Terminal CLI 结合 OpenAI Codex 辅助编写调试代码。
2. **大语言模型作为数据清洗器**：用 OpenAI API 自动分类开放式问卷回答（Open-ended Responses）与模糊文本。
3. **合成数据与模拟研究**：利用 LLM 生成符合现实人口统计分布的合成数据，解决数据隐私与样本不足问题。
