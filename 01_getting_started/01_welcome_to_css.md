# 🚀 欢迎来到计算社会科学 (Computational Social Science)

## 什么是计算社会科学？
计算社会科学（CSS）是将计算机技术（如数据处理、文本挖掘、统计建模）应用到政治学、社会学、经济学、公共管理等传统社科学科的交叉领域。

## 社科生学习 Python 的 3 大误区
1. **以为要先学完整本书的 Python 算法**：社科研究主要使用数据分析处理库（Pandas, Statsmodels, Seaborn），不需要掌握复杂的数据结构与底层算法。
2. **使用理工科示例练习**：花大量时间分析基因序列或物理小车运动，不如直接分析一份问卷调查（Survey Data）。
3. **追求复杂的深度学习**：在社会科学中，**可解释性 (Interpretability)** 和 **因果推断 (Causal Inference)** 远比高准确率的黑盒模型更重要。
